# 这组题在考什么

::: cue
4 道题都在考哪一句话？
:::

4 道题全是定义题，考的就是正课 2.1 那句定义和前驱后继的说法：

::: def
线性表是具有[相同数据类型]{.red}的 $n\,(n\ge0)$ 个[数据元素]{.red}的[有限]{.red}[序列]{.red}。除第一个元素外，每个元素有且仅有一个直接前驱；除最后一个元素外，每个元素有且仅有一个直接后继。
:::

| 题号 | 考点 | 答案 |
|---|---|---|
| 01 | 线性表由什么组成 | C |
| 02 | 哪个描述是线性表 | B |
| 03 | 前驱、后继的个数 | A |
| 04 | 没有前驱也没有后继的情况 | A |

::: fix
**这节的习题讲解视频不用看。** 4 道题都只是复述定义，没有正课和书上之外的新内容，也没有需要截图的图。视频里有两处口误，下面对应的题里已经标出。
:::

::: cue
线性表的元素是数据元素还是数据项？
:::

::: {.q title="01"}
线性表是具有 $n$ 个（　）的有限序列。

| A. 数据表　　　　B. 字符　　　　C. 数据元素　　　　D. 数据项
:::

[**答案：C**]{.red}

::: video
直接套定义。A 数据表只是把元素排成表格的一种组织形式；B 字符只是一种数据类型，"$n$ 个字符的有限序列是线性表"成立，反过来"线性表是 $n$ 个字符的有限序列"就不成立了；D 数据项只是数据元素的组成部分，比如学生的学号、姓名、性别。
:::

::: jiexi
线性表是由具有相同数据类型的有限数据元素组成的，数据元素是由数据项组成的。
:::

::: fix
习题讲解视频里说数据项是"构成数据元素的**基本单位**"，这是口误。按正课 1.1：[数据元素是基本单位，数据项是最小单位]{.red}（不可再分）。
:::

::: cue
集合、无限序列、存储结构，为什么都不是线性表？
:::

::: {.q title="02"}
下列几种描述中，（　）是一个线性表。

| A. 由 $n$ 个实数组成的集合
| B. 由 100 个字符组成的序列
| C. 所有整数组成的序列
| D. 邻接表
:::

[**答案：B**]{.red}

::: video
抓住"相同数据类型"和"有限序列"两个关键点，逐个排除：A 同类型、有限，但它是**集合**，集合里的元素没有先后，没有前驱后继；C 所有整数是无限的；D 邻接表是图的一种存储结构，根本不是逻辑结构。只有 B 三条全满足。
:::

::: jiexi
线性表定义的要求为：相同数据类型、有限序列。C 的元素个数是无穷个，错误；A 集合中的元素没有前后驱关系，错误；D 属于一种存储结构，本题要求选出的是一个具体的线性表，不要将二者混为一谈。
:::

::: recall
三个错误选项正好各缺定义里的一条：

::: {.tbl widths="1.2,1,1,1"}
| 选项 | 同类型 | 有限 | 序列（有先后） |
|---|---|---|---|
| A. $n$ 个实数的集合 | ✓ | ✓ | [✗]{.red} |
| B. 100 个字符的序列 | ✓ | ✓ | ✓ |
| C. 所有整数的序列 | ✓ | [✗]{.red} | ✓ |
:::

D 是另一层面的错误。正课 2.1 笔记里书上的注意：线性表是**逻辑结构**，顺序表、链表是**存储结构**；邻接表和它们一样是存储结构（图的，第 6 章学）。C 选项就是正课里老师举的那个反例。
:::

::: cue
除开始元素外，每个元素有几个前驱？
:::

::: {.q title="03"}
在线性表中，除开始元素外，每个元素（　）。

| A. 只有唯一的前驱元素　　　　B. 只有唯一的后继元素
| C. 有多个前驱元素　　　　　　D. 有多个后继元素
:::

[**答案：A**]{.red}

::: video
举例 $(A,B,C,D)$：除了开头的 $A$，$B$、$C$、$D$ 都有且仅有一个前驱。B 不对，因为最后一个元素 $D$ 没有后继；C、D 不对，线性表是一对一的关系，不存在多个前驱或多个后继。
:::

::: jiexi
线性表中，除最后一个（或第一个）元素外，每个元素都只有一个后继（或前驱）元素。
:::

::: fix
习题讲解视频里老师复述书上定义时说成"除了第一个元素之外，每个元素有且仅有一个直接**后继**"，这是口误：除第一个元素外的是[直接前驱]{.u}，除最后一个元素外的才是直接后继。他后面举例时用的是对的。
:::

::: add
做这类题先对"开始"还是"最后"：**开始元素没有前驱，最后元素没有后继**。题干说"除开始元素外"，就是在问前驱。
:::

::: cue
既没有前驱也没有后继，说明表里有几个元素？
:::

::: {.q title="04"}
若非空线性表中的元素既没有直接前驱，又没有直接后继，则该表中有（　）个元素。

| A. 1　　　　B. 2　　　　C. 3　　　　D. $n$
:::

[**答案：A**]{.red}

::: video
只要有两个及以上的元素，第一个就有后继，第二个就有前驱。既没前驱又没后继，只能是孤零零的一个元素。
:::

::: jiexi
线性表中的第一个元素没有直接前驱，最后一个元素没有直接后继；当线性表中仅有一个元素时，该元素既没有直接前驱，又没有直接后继。
:::

::: add
仅有的这个元素既是表头元素 $a_1$，也是表尾元素 $a_n$（此时 $n=1$）。题干的"非空"是为了排除空表，空表里根本没有元素可谈。
:::

::: summary
**这 4 题考的都是定义。** 线性表的元素是数据元素（不是数据项、不是某种具体类型），要同类型、有限、有先后；集合缺"先后"，无限序列缺"有限"，邻接表、顺序表、链表是存储结构，和线性表这个逻辑结构不在一个层面。前驱后继：开头没前驱、末尾没后继，其余各有且仅有一个；只有一个元素时两样都没有。

**自测**：① "由 $n$ 个整数组成的集合"为什么不是线性表？② 线性表 $(a_1)$ 中 $a_1$ 是表头还是表尾？
:::
