# 这份笔记怎么读

::: cue
这 18 题用的是哪一套方法？
:::

这是和旧版 1.2 课后习题并行的**统一版**，旧版一字未动，供你对比。

所有求时间复杂度的题只用正课笔记统一版第三层的**同一套方法**，不另起体系：

::: recall
**通用方法（三步）**（正课 1.2.2 统一版·第三层）

1. **定基本操作**：最深层循环体里的一条语句；递归就数函数调用。
2. **把执行次数写成求和**：
   - 情形 ① 单层循环：数循环变量取了几个值，用"**最后一次进得去、下一次进不去**"定出最后一个值；
   - 情形 ② 多层循环：对外层每个取值 $i$，把内层次数 $g(i)$ 加起来；
   - 情形 ③ 递归：按递归参数分层，把每层的调用次数加起来。
3. **取数量级**：只会出现三种和式，常数相加 $\sim$ 项数，等差 $\sim m^2$，等比 $\sim$ 最后一项。
:::

# 一、概念题

::: cue
算法的五个特性 vs 好算法的标准？
:::

::: {.q title="01"}
一个算法应该具有（　）等重要特性。

| A. 可维护性、可读性和可行性　　B. 可行性、确定性和有穷性
| C. 确定性、有穷性和可靠性　　　D. 可读性、正确性和可行性
:::

[**答案：B**]{.red}

**特性**是"是不是算法"的门槛，五个缺一不可：有穷性、确定性、可行性、输入、输出。**好算法的目标**是另一回事：正确性、可读性、健壮性、高效率与低存储量需求。A、C、D 都混进了"好不好"的词（可维护性、可读性、可靠性、正确性）。

::: recall
正课 1.2.1：必须有的是五个特性；最好有的是四个目标。
:::

::: cue
衡量时间效率看 CPU 时间吗？
:::

::: {.q title="02"}
下列关于算法的说法中，正确的是（　）。

| A. 算法的时间效率取决于算法执行所花的 CPU 时间
| B. 在算法设计中不允许用牺牲空间效率的方式来换取好的时间效率
| C. 算法必须具备有穷性、确定性等五个特性
| D. 通常用时间效率和空间效率来衡量算法的优劣
:::

[**答案：C**]{.red}

- A 错：CPU 时间还取决于机器。时间复杂度用**计数模型**把时间换成执行次数，正是为了剥离机器的影响（正课统一版·第一层 §0、§2）。
- B 错：时间要求高的场景就该用空间换时间。
- D 错：时空效率只是"高效率与低存储量需求"一条，还有正确性、可读性、健壮性。

::: cue
$O(n^2)$ 说的是什么和 $n^2$ 的关系？
:::

::: {.q title="03"}
某算法的时间复杂度为 $O(n^2)$，则表示该算法的（　）。

| A. 问题规模是 $n^2$　　　B. 执行时间等于 $n^2$
| C. 执行时间与 $n^2$ 成正比　D. 问题规模与 $n^2$ 成正比
:::

[**答案：C**]{.red}

**按定义判断**：时间复杂度 $O(n^2)$ 的意思是总执行次数 $T(n)$ 与 $n^2$ **同阶**，即 $c_1n^2\le T(n)\le c_2n^2$（$n$ 足够大）。计数模型下执行时间 $\propto T(n)$，所以执行时间也夹在 $n^2$ 的两个常数倍之间。C 的"成正比"就是这个意思（准确说法是"同数量级"，不是严格的等比例）。B 把"同阶"说成"相等"，错；A、D 把 $n^2$ 说成问题规模，错，问题规模仍是 $n$。

::: video
老师的说法和这里一致：最准确的应是"基本语句的执行次数与 $n^2$ 同数量级"，C 最接近；C 说"执行时间"不够精确，因为时间复杂度不考虑具体机器。
:::

::: jiexi
书上解析写"$T(n)\le cn^2$"，这是王道书的**上界**写法。考试里 $O$ 指最紧的上界，也就是同阶（正课统一版·第一层 §5 的符号统一），两种说法对这题给出同一个答案。
:::

::: cue
$O(1)$ 空间 = 不用空间？
:::

::: {.q title="04"}
若某算法的空间复杂度为 $O(1)$，则表示该算法（　）。

| A. 不需要任何辅助空间　　　　　B. 所需辅助空间大小与问题规模 $n$ 无关
| C. 不需要任何空间　　　　　　　D. 所需空间大小与问题规模 $n$ 无关
:::

[**答案：B**]{.red}

空间复杂度只计**辅助空间**（指令、常数、输入数据都不计）。$O(1)$ 指辅助空间不随 $n$ 增长：定义 1 个、100 个、1000 个与 $n$ 无关的变量都是 $O(1)$；开 `a[n]` 是 $O(n)$，开 `a[n][n]` 是 $O(n^2)$。A、C 错，循环变量本身就是辅助空间，指令也占空间。D 错在"空间"和"辅助空间"一字之差：数组 `a[n]` 作为输入传进来时，总空间与 $n$ 有关，辅助空间仍可以是 $O(1)$。

::: recall
正课 1.2.3：输入数据所占空间不计入空间复杂度。
:::

::: cue
比较复杂度时，系数和带负号的低阶项怎么处理？
:::

::: {.q title="05"}
下列关于时间复杂度的函数中，时间复杂度最小的是（　）。

| A. $T_1(n)=n\log_2 n+5000n$　　B. $T_2(n)=n^2-8000n$
| C. $T_3(n)=n\log_2 n-6000n$　　D. $T_4(n)=20000\log_2 n$
:::

[**答案：D**]{.red}

用**定理 1**（只留最高阶项、去系数，带负号的低阶项也可以扔）和**定理 3**（常对幂指阶）：

- A：$\frac{T_1}{n\log_2 n}=1+\frac{5000}{\log_2 n}\to1$，同阶 $n\log_2 n$；
- B：$\frac{T_2}{n^2}=1-\frac{8000}{n}\to1$，同阶 $n^2$；
- C：同 A 的算法，同阶 $n\log_2 n$；
- D：$20000\log_2 n$ 同阶 $\log_2 n$，最小。

::: pitfall
D 前面的 20000 只是常数。小 $n$ 时 D 确实比 A 大，但数量级只看 $n\to\infty$。
:::

# 二、情形 ①：单层循环

每题都是同一个动作：写出循环变量的取值 $v_0,v_1,\dots$，用"最后一次进得去 $v_c$、下一次进不去 $v_{c+1}$"夹出 $c$，次数就是取值的个数。

::: cue
变量每次乘 2，循环几次？
:::

::: {.q title="06"}
下列算法的时间复杂度为（　）。

```c
void fun(int n){
    int i=1;
    while(i<=n)
        i=i*2;
}
```

| A. $O(n)$　　B. $O(n^2)$　　C. $O(n\log_2 n)$　　D. $O(\log_2 n)$
:::

[**答案：D**]{.red}

1. **基本操作**：`i=i*2`。
2. **取值**：$i=2^0,2^1,\dots,2^c$。最后一次进得去 $2^c\le n$，下一次进不去 $2^{c+1}>n$，得 $c\le\log_2 n<c+1$，$c=\lfloor\log_2 n\rfloor$。次数 $=c+1$。
3. **数量级**：$\lfloor\log_2 n\rfloor+1$ 与 $\log_2 n$ 同阶，$O(\log_2 n)$。

::: video
老师承认这题一眼就能看出，故意用表格慢慢做，是为了练这套方法，2022、2025 那种题才用得上。
:::

::: recall
就是正课小练习 1（指数递增型爱你），引理和不等式完全一样。
:::

::: cue
条件是 $i^3\le n$，循环几次？
:::

::: {.q title="07"}
下列算法的时间复杂度为（　）。

```c
void fun(int n){
    int i=0;
    while(i*i*i<=n)
        i++;
}
```

| A. $O(n)$　　B. $O(n\log_2 n)$　　C. $O(\sqrt[3]{n})$　　D. $O(\sqrt n)$
:::

[**答案：C**]{.red}

1. **基本操作**：`i++`。
2. **取值**：$i=0,1,\dots,c$。最后一次进得去 $c^3\le n$，下一次进不去 $(c+1)^3>n$，开三次方得 $c\le\sqrt[3]{n}<c+1$，$c=\lfloor\sqrt[3]{n}\rfloor$。次数 $=c+1$。
3. **数量级**：$O(\sqrt[3]{n})$。

::: cue
初值 2、条件 $x<n/2$，会改变数量级吗？
:::

::: {.q title="12 · 2011 统考真题"}
设 $n$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（　）。

```c
x=2;
while(x<n/2)
    x=2*x;
```

| A. $O(\log_2 n)$　　B. $O(n)$　　C. $O(n\log_2 n)$　　D. $O(n^2)$
:::

[**答案：A**]{.red}

1. **基本操作**：`x=2*x`。
2. **取值**：$x=2^1,2^2,\dots,2^c$，共 $c$ 个。最后一次进得去 $2^c<\frac n2$，下一次进不去 $2^{c+1}\ge\frac n2$。取对数：$c<\log_2 n-1\le c+1$，即 $\log_2 n-2\le c<\log_2 n-1$。
3. **数量级**：$c$ 夹在 $\log_2 n$ 减两个常数之间，同阶，$O(\log_2 n)$。

::: add
和 06 比，初值从 1 变 2、上界从 $n$ 变 $n/2$，在不等式里只变成"减一个常数"，不改变数量级。真题常这样改头换面。
:::

::: cue
`sum += ++i` 里循环变量是谁？
:::

::: {.q title="15 · 2017 统考真题"}
下列函数的时间复杂度是（　）。

```c
int func(int n){
    int i=0, sum=0;
    while(sum<n) sum += ++i;
    return i;
}
```

| A. $O(\log_2 n)$　　B. $O(n^{1/2})$　　C. $O(n)$　　D. $O(n\log_2 n)$
:::

[**答案：B**]{.red}

1. **基本操作**：`sum += ++i`，它等于先 `i=i+1` 再 `sum=sum+i`。
2. **取值**：循环条件看的是 `sum`，所以要写的是 `sum` 的取值。进入第 $k+1$ 次判断时 $\text{sum}=s_k=1+2+\cdots+k=\frac{k(k+1)}{2}$（$k=0,1,2,\dots$）。

   | 判断时的 sum | $s_0=0$ | $s_1=1$ | $s_2=3$ | $\cdots$ | $s_c$（最后一次进入） |
   |---|---|---|---|---|---|
   | 执行次数 | 1 | 1 | 1 | $\cdots$ | 1 |

   次数 $=c+1$。最后一次进得去 $s_c<n$，下一次进不去 $s_{c+1}\ge n$：
   $$\frac{c^2}{2}\le\frac{c(c+1)}{2}<n\le\frac{(c+1)(c+2)}{2}\le\frac{(c+2)^2}{2}.$$
   所以 $c<\sqrt{2n}$ 且 $c+2\ge\sqrt{2n}$，次数 $c+1$ 夹在 $\sqrt{2n}-1$ 与 $\sqrt{2n}+1$ 之间。
3. **数量级**：与 $\sqrt n$ 同阶，$O(n^{1/2})$。

::: video
老师说可以配方解不等式，但"高手"直接看数量级：两边都是 $k^2$ 量级，$n\approx k^2$，$k\approx\sqrt n$。这就是第 3 步"只要夹出同阶的上下界"，上面两行不等式就是它的严格版。
:::

::: cue
条件 $(x+1)^2\le n$，循环几次？
:::

::: {.q title="16 · 2019 统考真题"}
设 $n$ 是描述问题规模的非负整数，下列程序段的时间复杂度是（　）。

```c
x=0;
while(n>=(x+1)*(x+1))
    x=x+1;
```

| A. $O(\log_2 n)$　　B. $O(n^{1/2})$　　C. $O(n)$　　D. $O(n^2)$
:::

[**答案：B**]{.red}

1. **基本操作**：`x=x+1`。
2. **取值**：$x=0,1,\dots,c$。最后一次进得去 $(c+1)^2\le n$，下一次进不去 $(c+2)^2>n$，开方得 $c+1\le\sqrt n<c+2$，所以次数 $c+1=\lfloor\sqrt n\rfloor$（$n\ge1$）。
3. **数量级**：$O(\sqrt n)$。

::: add
06、07、12、16 是正课统一版第三层那张表的两行："变量 +1、条件 $v^k\le n$ → $n^{1/k}$"和"变量 ×2 → $\log_2 n$"。15 不在表里，因为它的循环变量 `sum` 每次加的量在变，只能老老实实写出 $s_k$，但用的还是同一个引理。
:::

# 三、情形 ②：多层循环

每题都是同一个动作：先用情形 ① 写出外层取值 $i_0,\dots,i_c$，再求每个取值下内层的次数 $g(i)$，最后 $x=\sum g(i)$，用三种和式取数量级。

::: cue
"最坏情况"在这题里是什么意思？内层次数随外层变化怎么求？
:::

::: {.q title="08"}
某个程序段如下：

```c
for(i=n-1;i>1;i--)
    for(j=1;j<i;j++)
        if(A[j]>A[j+1])
            A[j]与A[j+1]对换;
```

其中 $n$ 为正整数，则最后一行语句的频度在最坏情况下是（　）。

| A. $O(n)$　　B. $O(n\log_2 n)$　　C. $O(n^3)$　　D. $O(n^2)$
:::

[**答案：D**]{.red}

**先处理"最坏"**（正课统一版·第四层）：交换语句的次数取决于数组内容；最坏就是 `if` 每次都成立，交换次数 = 内层循环体的次数。

1. **基本操作**：内层循环体（最坏时就是交换语句）。
2. **求和**：外层 $i=n-1,n-2,\dots,2$；对每个 $i$，内层 $j=1,\dots,i-1$，$g(i)=i-1$。

   | 外层 $i$ | 内层 $j$ | $g(i)$ |
   |---|---|---|
   | $n-1$ | $1\sim n-2$ | $n-2$ |
   | $n-2$ | $1\sim n-3$ | $n-3$ |
   | $\cdots$ | $\cdots$ | $\cdots$ |
   | $2$ | $1$ | $1$ |

   $x=1+2+\cdots+(n-2)=\dfrac{(n-1)(n-2)}{2}$。
3. **数量级**：等差和式，与 $n^2$ 同阶，$O(n^2)$。

::: fix
习题讲解视频里老师把第一行的次数写成了 $n-1$，总和算成 $\frac{n(n-1)}{2}$，[这里算错了]{.red}：$i=n-1$ 时 $j$ 从 1 到 $n-2$，只有 $n-2$ 次。数量级不受影响，但问精确次数时（如 10 题）就会选错。
:::

::: add
这段代码是**冒泡排序**（第 8 章）。
:::

::: cue
有 if-else 两个分支时，复杂度取哪个？为什么？
:::

::: {.q title="09"}
下列程序段的时间复杂度为（　）。

```c
if(n>=0){
    for(int i=0;i<n;i++)
        for(int j=0;j<n;j++)
            printf("输入数据大于或等于零\n");
}
else{
    for(int j=0;j<n;j++)
        printf("输入数据小于零\n");
}
```

| A. $O(n^2)$　　B. $O(n)$　　C. $O(1)$　　D. $O(n\log_2 n)$
:::

[**答案：A**]{.red}

1. **两个分支各算一遍**：
   - if 分支：外层 $i=0,\dots,n-1$ 共 $n$ 个取值，每个 $g(i)=n$（不随 $i$ 变化），$x=n\cdot n=n^2$（乘法规则）；
   - else 分支：单层循环，$x=n$。
2. **取最大的分支**：这正是**最坏情况**的定义（对所有可能的执行路径取次数的最大值，正课统一版·第五层第 5 条），所以是 $O(n^2)$。

::: video
有同学说"$n<0$ 时 else 里的循环根本不执行，这题有问题"。老师的回答：分析复杂度时只看代码结构，不代入 $n$ 的具体值，每个分支分别算、取最大。
:::

::: add
换一个更严格的角度也得到同一个答案：复杂度看的是 $n\to\infty$，这时 $n\ge0$ 恒成立，实际走的就是 if 分支，$n^2$ 次。
:::

::: cue
题目问"执行次数"时，要算到多精确？
:::

::: {.q title="10"}
下列算法中加下划线的语句（`m++`）的执行次数为（　）。

```c
int m=0,i,j;
for(i=1;i<=n;i++)
    for(j=1;j<=2*i;j++)
        m++;
```

| A. $n(n+1)$　　B. $n$　　C. $n+1$　　D. $n^2$
:::

[**答案：A**]{.red}

1. **基本操作**：`m++`。
2. **求和**：外层 $i=1,\dots,n$；内层 $j=1,\dots,2i$，$g(i)=2i$。
   $$x=2+4+\cdots+2n=2(1+2+\cdots+n)=n(n+1).$$
3. 这题问的是**执行次数**，所以停在第 2 步，不取数量级。

::: pitfall
D 的 $n^2$ 与 A 同阶，专门给只算数量级的人准备（正课统一版·第五层第 4 条）。
:::

::: cue
外层 ×2、内层固定 $n$ 次，能直接相乘吗？
:::

::: {.q title="14 · 2014 统考真题"}
下列程序段的时间复杂度是（　）。

```c
count=0;
for(k=1;k<=n;k*=2)
    for(j=1;j<=n;j++)
        count++;
```

| A. $O(\log_2 n)$　　B. $O(n)$　　C. $O(n\log_2 n)$　　D. $O(n^2)$
:::

[**答案：C**]{.red}

1. **基本操作**：`count++`。
2. **求和**：外层 $k=2^0,\dots,2^c$，同 06 题 $c=\lfloor\log_2 n\rfloor$，共 $c+1$ 个取值；内层 $g(k)=n$，**不随 $k$ 变化**。
   $$x=\underbrace{n+n+\cdots+n}_{c+1\text{ 项}}=n(\lfloor\log_2 n\rfloor+1).$$
3. **数量级**：$O(n\log_2 n)$。

::: add
$g$ 不随外层变化，所以可以直接用乘法规则：外层 $O(\log_2 n)$ × 内层 $O(n)$。下面 17、18 题的 $g$ 随外层变化，就不能直接乘了。
:::

::: cue
外层 ×2、内层跑 $i$ 次，为什么不是 $n\log_2 n$？
:::

::: {.q title="17 · 2022 统考真题"}
下列程序段的时间复杂度是（　）。

```c
int sum=0;
for(int i=1;i<n;i*=2)
    for(int j=0;j<i;j++)
        sum++;
```

| A. $O(\log_2 n)$　　B. $O(n)$　　C. $O(n\log_2 n)$　　D. $O(n^2)$
:::

[**答案：B**]{.red}

1. **基本操作**：`sum++`。
2. **求和**：外层 $i=2^0,2^1,\dots,2^t$，最后一次进得去 $2^t<n$，下一次进不去 $2^{t+1}\ge n$；内层 $j=0,\dots,i-1$，$g(i)=i$。

   | 外层 $i$ | 内层 $j$ | $g(i)$ |
   |---|---|---|
   | $2^0$ | $0$ | 1 |
   | $2^1$ | $0\sim1$ | 2 |
   | $\cdots$ | $\cdots$ | $\cdots$ |
   | $2^t$ | $0\sim 2^t-1$ | $2^t$ |

   $x=1+2+\cdots+2^t=2^{t+1}-1$。
3. **数量级**：等比和式，与最后一项同阶。代入 $n\le2^{t+1}<2n$：$n-1\le x<2n-1$，所以 $O(n)$。

::: pitfall
错选 C 的原因：外层 $\log_2 n$ 轮 × 内层"最多 $n$ 次"只得到**上界** $n\log_2 n$，不是同阶。内层是 1、2、4…，前面所有行加起来还不到最后一行（等比和式），总数与最后一行同阶，约 $n$。
:::

::: video
这题的讲解换了一种说法：先拆外层，列出 $i$ 的取值；对每个取值求内层次数；最后求和。这正是情形 ②。书上解析叫"把多层循环转换成多个并列的单层循环"，也是同一件事。

讲完后视频总结了**"类型一 / 类型二"**：

- 类型一：每层都是 `i++`、`j++` 这种 +1 的，"每层的最大范围相乘"即可；内层依赖外层（如 `j<i`）时，把 $i$ 放大成 $n$ 再乘。
- 类型二：有 `i*=2` 之类的，必须逐层拆开算。
:::

::: add
**"类型一 / 类型二"放回统一方法**：

- **类型二**就是情形 ② 本身，没有新东西。
- **类型一**是情形 ② 的一条捷径。"每层最大范围相乘"只给出**上界**；它在每层都是 +1、边界是 $n$ 或外层变量时恰好同阶，理由是下界也能证出同阶：以两层 `for(i=0;i<n;i++) for(j=0;j<i;j++)` 为例，只看 $i\ge n/2$ 的那约 $n/2$ 个取值，每个都有 $g(i)=i\ge n/2$，所以 $x\ge\frac n2\cdot\frac n2=\frac{n^2}{4}$，与上界 $n^2$ 同阶。
- 本题就是捷径失效的例子：外层 ×2，相乘得到的 $n\log_2 n$ 不同阶。所以捷径不必记，记情形 ② 就够了。
:::

::: fix
书上解析写"对于单层循环如 `for(j=0;j<=i;j++) sum++;`，可以直接数出执行次数为 $i$"，`j<=i` 是笔误，应为 `j<i`（`j<=i` 会执行 $i+1$ 次）。

**对旧版的更正**：旧版 1.2 课后习题第 18 题的"视频讲解"框写"18 题的讲解换了一位老师，最后总结了两类循环题"。按习题讲解字幕 P5 的顺序，"类型一 / 类型二"的总结紧跟在本题（2022）之后，18 题（2025）是另一段讲解，讲的是两步法。这是**更正**。
:::

::: cue
外层到 $\sqrt n$、内层跑 $i$ 次，总次数？
:::

::: {.q title="18 · 2025 统考真题"}
下列程序段的时间复杂度是（　）。

```c
int count=0,i,j;
for(i=1;i*i<=n;i++)
    for(j=1;j<=i;j++)
        count++;
```

| A. $O(\log_2 n)$　　B. $O(n)$　　C. $O(n\log_2 n)$　　D. $O(n^2)$
:::

[**答案：B**]{.red}

1. **基本操作**：`count++`。
2. **求和**：外层 $i=1,\dots,m$，最后一次进得去 $m^2\le n$，下一次进不去 $(m+1)^2>n$，得 $m=\lfloor\sqrt n\rfloor$；内层 $j=1,\dots,i$，$g(i)=i$。
   $$x=1+2+\cdots+m=\frac{m(m+1)}{2}.$$
3. **数量级**：等差和式，与 $m^2$ 同阶；又 $m\le\sqrt n<m+1$，所以 $m^2$ 与 $n$ 同阶（$\frac{(\sqrt n-1)^2}{n}\to1$）。$O(n)$。

::: video
这段讲解用"两步法"：第一步算关键指令执行次数 $T(n)$，第二步只保留最高次项、去系数、套上大 O。二重循环看成"$\sqrt n$ 个并列的单层循环"。这就是第 2、3 步。
:::

::: fix
书上和习题讲解视频都写 $T=\frac n2+\frac{\lfloor\sqrt n\rfloor}{2}$ 并用了等号，只在 $n$ 是完全平方数时成立；精确值是 $\frac{m(m+1)}{2}$，$m=\lfloor\sqrt n\rfloor$。不影响 $O(n)$。
:::

# 四、情形 ③：递归

每题都是同一个动作：每次调用自身只做常数次操作，所以数**调用总次数**；按递归参数分层，把每层的调用次数加起来。

::: cue
递归数什么？`2*Func(n/2)+n` 里的 2 和 +n 要不要管？
:::

::: {.q title="11"}
下列函数代码的时间复杂度是（　）。

```c
int Func(int n){
    if(n==1) return 1;
    else return 2*Func(n/2)+n;
}
```

| A. $O(n)$　　B. $O(n\log_2 n)$　　C. $O(\log_2 n)$　　D. $O(n^2)$
:::

[**答案：C**]{.red}

1. **基本操作**：一次调用。一次调用自身只做一次判断、一次乘法、一次加法，是常数。
2. **求和**：参数依次是 $n,\lfloor n/2\rfloor,\lfloor n/4\rfloor,\dots,1$，每层调用 1 次。

   | 递归参数 | $n$ | $n/2$ | $n/4$ | $\cdots$ | $1$ |
   |---|---|---|---|---|---|
   | 这层调用次数 | 1 | 1 | 1 | $\cdots$ | 1 |

   参数每次减半，和 06 题的取值反过来，层数 $=\lfloor\log_2 n\rfloor+1$。
3. **数量级**：常数相加，与层数同阶，$O(\log_2 n)$。

::: pitfall
`2*` 和 `+n` 是一次乘法和一次加法，**不是循环**，不会让一次调用做 $n$ 次操作，所以不影响调用次数。
:::

**习题讲解视频的改编题**：返回语句改成 `return Func(n/2)*Func(n/2);`（不做编译优化），复杂度是多少？

同一个动作，只是每次调用自身要调**两次**下一层，所以每层的调用次数翻倍：

```{=latex}
\begin{center}
\begin{tikzpicture}[level distance=9mm,
  every node/.style={draw=wdblue,fill=wdblue!6,rounded corners=2pt,font=\scriptsize,minimum height=4.5mm,inner sep=2pt},
  level 1/.style={sibling distance=36mm},level 2/.style={sibling distance=18mm},level 3/.style={sibling distance=9mm}]
\node {$n$}
  child {node {$n/2$} child {node {$n/4$} child {node {1}} child {node {1}}} child {node {$n/4$} child {node {1}} child {node {1}}}}
  child {node {$n/2$} child {node {$n/4$} child {node {1}} child {node {1}}} child {node {$n/4$} child {node {1}} child {node {1}}}};
\begin{scope}[every node/.style={font=\scriptsize,text=wdred}]
\node at (4.3,0) {1 次};
\node at (4.3,-0.9) {2 次};
\node at (4.3,-1.8) {4 次};
\node at (4.3,-2.7) {$n$ 次};
\end{scope}
\end{tikzpicture}
\end{center}
```

| 递归参数 | $n$ | $n/2$ | $n/4$ | $\cdots$ | $1$ |
|---|---|---|---|---|---|
| 这层调用次数 | 1 | 2 | 4 | $\cdots$ | $n$ |

设 $n=2^c$，$x=1+2+\cdots+2^c=2^{c+1}-1=2n-1$，等比和式，与最后一项 $n$ 同阶，[$O(n)$]{.red}。

::: cue
`n*fact(n-1)` 调用几次？
:::

::: {.q title="13 · 2012 统考真题"}
求整数 $n$（$n\ge 0$）的阶乘的算法如下，其时间复杂度是（　）。

```c
int fact(int n){
    if(n<=1) return 1;
    return n*fact(n-1);
}
```

| A. $O(\log_2 n)$　　B. $O(n)$　　C. $O(n\log_2 n)$　　D. $O(n^2)$
:::

[**答案：B**]{.red}

1. **基本操作**：一次调用（一次判断、一次乘法）。
2. **求和**：参数 $n,n-1,\dots,1$，每层 1 次，共 $n$ 次（$n\ge1$）。这就是王道书的递推式 $T(n)=1+T(n-1)=\cdots=(n-1)+T(1)$。
3. **数量级**：$O(n)$。乘号前的 $n$ 和 11 题的系数一样，不影响调用次数。

::: recall
正课 1.2.3：本题空间复杂度也是 $O(n)$，因为递归深度为 $n$。时间看调用**总次数**，空间看调用**深度**；11 题改编题时间 $O(n)$，深度只有 $\log_2 n$，空间 $O(\log_2 n)$。
:::

::: fix
书上 11、13 题解析写"每次递归执行的基本语句是 `if(n==1) return 1;`"，意思是每次调用只做常数次操作，总次数 = 调用次数 × 常数，与上面第 1 步一致。
:::

::: exam
三处最容易错，都在第 3 步：

1. 内层次数随外层变化时**不能直接相乘**，要求和（17 题）。
2. 外层 ×2、内层跟着外层变量走 → **等比** → 与最后一项同阶 → $O(n)$。
3. 问"执行次数"停在第 2 步给精确值（10 题）；问"复杂度"才做第 3 步。
:::

::: summary
**全部 18 题只用一套方法。** 前 5 题检验定义：特性 vs 目标；计数模型剥离机器；$O(n^2)$ 指次数与 $n^2$ 同阶；$O(1)$ 空间指辅助空间与 $n$ 无关；比较复杂度只留最高阶项、去系数。

后 13 题都按三步做：① 定基本操作（最深层循环体，或一次递归调用）；② 写成求和（单层：最后一次进得去、下一次进不去；多层：对外层每个取值加内层次数；递归：分层加调用次数）；③ 用三种和式取数量级（常数相加 $\sim$ 项数，等差 $\sim m^2$，等比 $\sim$ 最后一项）。

习题讲解视频的表格法、拆循环、并列单层循环、两步法、"类型一 / 类型二"都是这三步的书写格式或捷径。

**自测**（都用三步写出来）：

1. `for(i=1;i<n;i*=3) for(j=0;j<i;j++) x++;`
2. `i=1; while(i*i<n) i*=2;`
3. 把 13 题改成 `return fact(n-1)+fact(n-1);`，时间、空间复杂度各是多少？
:::
