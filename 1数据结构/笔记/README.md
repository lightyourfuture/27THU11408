# 数据结构 · 康奈尔听课笔记

## 文件夹结构

```
笔记/
├── 正课笔记/第N章 …/      ← 正课笔记 PDF（只放成品）
├── 课后习题/第N章 …/      ← 课后习题笔记 PDF（只放成品）
├── 源码/第N章 …/          ← 每份笔记的 .md（内容源文件）和 .tex（LaTeX 源码），课件截图在 assets/
├── 参考资料/              ← 王道书各章节选
├── _build/                ← 排版脚本和模板
└── README.md
```

## 版式约定

- **左栏「线索 · 问题」**：每块知识对应一个自问，复习时遮住右栏自测。
- **右栏「笔记」**：老师主线（定义框、老师原话）+ 补充讲解（承上启下、大白话、背后的思想、王道书补充、勘误）。
- **底部「总结区」**：用自己的话复述本节，附自测题。
- 颜色：红 = 必记结论，蓝 = 定义 / 术语，绿 = 比喻，橙 = 易错，紫 = 背后的思想。

## 修改后重新生成 PDF

需要 pandoc、xelatex（含中文支持）、Noto CJK 字体、mermaid-cli：

```bash
bash _build/build.sh "源码/第1章 绪论/1.1 数据结构的基本概念.md"
```

生成的 PDF 自动放进 `正课笔记/` 或 `课后习题/`（文件名含"课后习题"的归后者），`.tex` 留在 `.md` 旁边。

Markdown 里可用的写法：`::: cue`（线索栏）、`::: {.def title="…"}`、`::: bridge / plain / deep / exam / pitfall / book / teacher / fix / summary`、`[文字]{.red}`、`[文字]{.u}`（下划线）、`![说明](assets/x.jpg){.slide width=0.7}`、```` ```mermaid ```` 作图。

目录：在 `.md` 开头的 front matter 里写 `toc: true`（可加 `toc-depth: 1` 只列大标题，默认列到二级标题），PDF 开头就会生成可点击的目录，每个大标题右侧和每页页脚左下角都有"回到目录"的链接。内容短的小节不写，就没有目录。

## 课后习题笔记

每小节的习题笔记单独一份，如 `1.1 课后习题.md`。额外可用的框：`::: {.q title="01"}`（题目，选项用 `| A. …` 逐行写）、`::: video`（视频讲解）、`::: jiexi`（书上解析）、`::: add`（我的补充）、`::: recall`（回顾正课）、`::: watch`（建议去看视频）。答案行写 `[**答案：C**]{.red}`。
